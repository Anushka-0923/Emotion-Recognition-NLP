# Emotion Recognition using NLP

This project uses Natural Language Processing (NLP) and Machine Learning techniques to classify emotions from textual data. The model analyzes text inputs and predicts emotions such as happiness, sadness, anger, fear, and surprise.

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Natural Language Processing (NLP)

## Features

* Text preprocessing and cleaning
* Feature extraction
* Emotion classification
* Model evaluation using standard ML metrics
